# 抖音 / 美团团购券 Demo

本功能用于下周 Demo，当前接入的是仓库内置的平台适配器，不代表已连接抖音或美团生产环境。

## Demo 券

| 平台 | 券码 | 套餐 | 面值 |
|---|---|---|---:|
| 抖音 | `DY-DEMO-1001` | 抖音咖啡双人团购套餐 | ¥8.80 |
| 美团 | `MT-DEMO-1001` | 美团到店 10 元代金券 | ¥10.00 |

H2 服务端每次重启都会重新生成这两张可用券；每张券只能成功核销一次。

## 演示流程

1. Cashier 登录、开台、点单并追加菜品。
2. 进入结账，选择“抖音团购”或“美团团购”。
3. 输入对应 Demo 券码并点击“验券”。
4. 核对套餐、脱敏券码、面值和 Demo 标识后，点击“确认核销”。
5. 券面值不足时，用现金补齐剩余金额。
6. Web Admin 打开“团购核销”，查看平台、套餐、`****1001`、关联订单、平台流水和核销时间。

## Demo 接口

- `POST /pos/group-buying-vouchers/validate`：终端 JWT，验券但不改变券状态。
- `POST /pos/group-buying-vouchers/redeem`：终端 JWT，幂等核销并关联订单与操作员。
- `GET /admin/group-buying-redemptions`：管理员 JWT，需要 `report.daily` 权限。

服务端只存券码 SHA-256 和后四位，不保存或返回完整券码。核销接口使用幂等键防止网络重试造成重复履约。

## 生产接入前必须完成

- 替换 Demo 适配器为抖音、美团正式验券/核销 API，并实现平台签名、重试和回调对账。
- 给终端登录增加设备密钥或证书，并绑定门店；当前 Demo 终端登录不能作为生产认证方案。
- 服务端校验平台门店、券适用商品和订单应付金额，不信任 POS 上报金额。
- 增加撤销核销、退款、日终差异对账、告警和完整审计。
- 使用持久化数据库；当前 H2 重启会清空核销记录。
