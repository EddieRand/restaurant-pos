## 查看经营指标

1. 从左侧导航进入 Dashboard。
2. 使用今天、昨天、近 7 天、本月或自定义日期范围。
3. 查看净营收、订单量、客流和客单价等 KPI。
4. 页面可见时数据会定时刷新；切到后台后暂停刷新。

Dashboard 展示的是服务端已同步的已结订单。如果 Cashier 刚完成结账，请等待同步后再核对。
