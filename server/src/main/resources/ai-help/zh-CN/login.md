## 登录 Web 管理后台

1. 打开 Web 管理后台的 `/login` 页面。
2. 输入管理员邮箱和密码。
3. 点击“登录”进入 Dashboard。

Demo 默认管理员账号为 `admin@pos.local`，密码为 `admin123`。Cashier 使用 PIN 登录，Demo PIN 为 `2222`。账号无权限时应联系管理员调整角色，不要共享管理员密码。
